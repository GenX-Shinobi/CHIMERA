# CHIMERA

**Controlled Hierarchical Intelligence, Modularity, Efficiency, Resilience & Adaptation**

An open-source, free-to-use, platform-independent framework for building, governing and coordinating reusable AI workforces.

## Project status

CHIMERA is in its governance and documentation planning stage. Prompt Builder v5.4.0 was publicly released on 2026-11-21. CH-FOUNDATION-01 (documentation reconciliation) merged on 2026-11-22. The Administrator charter design was approved on 2026-11-22 and is consolidated under CH-GOVERNANCE-02 as documentation only. Runtime implementation and pilot integration remain unauthorized.

## Governance principles

- Human ownership and explicit approval for material changes.
- Universal statutes and least-privilege authority.
- Governed, traceable persistent memory; memory does not create authority.
- Four memory levels: Working, Episodic, Semantic and Procedural.
- Separate organizational and project histories, with verified and scoped learning transfer.
- Optional integrations only; no mandatory paid platform dependencies.

CHIMERA is a separate project from [AI Prompt Builder Hub](https://github.com/GenX-Shinobi/Prompt-Builder). Prompt Builder may become a future adopter only after its v5.4.0 public release and separate Owner authorization.

**Planning baseline only:** repository documents record approved directions and open proposals. They do not authorize implementation beyond an Owner-approved milestone.
