# CHIMERA — Roadmap

**Status:** Planning baseline; implementation paused pending public release of AI Prompt Builder Hub v5.4.0 and subsequent Owner authorization.  
**Repository:** https://github.com/GenX-Shinobi/CHIMERA

## Mission
Build a free-to-use, open-source, platform-independent framework for creating, governing, coordinating and improving reusable AI workforces.

## Guiding principles
- Establish governance and memory foundations before building a large workforce.
- Preserve human ownership and explicit approval for material changes.
- Keep provider-specific integrations optional; do not make one platform a core dependency.
- Add roles only when demonstrated value exceeds coordination, context, compute and maintenance overhead.
- Separate CHIMERA-wide knowledge from project-specific knowledge, authority and data.
- Use evidence and bounded pilots rather than speculative complexity.
- Maintain governed, traceable memory and append-only historical integrity.

## Exploratory backlog — not active requirements
- Interactive Workforce Designer: guided session to gather goals, workflows, tasks, workload, constraints and automation needs; draft a justified workforce plan with roles, responsibilities, task assignments, dependencies, capabilities, permissions and staged implementation. CHIMERA cannot appoint/activate employees or grant permissions without Owner approval.

## Authorization boundaries
This roadmap is a planning document, not permission to implement every phase. The Owner authorizes milestones and material changes. Within an approved milestone, routine work may proceed under bounded autonomy. Statute changes, authority changes, permanent appointments, major architecture/dependency changes, scope changes and publication/release actions require explicit Owner approval.
